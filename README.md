# over_limit_pack

Minecraft Java **26.2** 向けデータパックです（Mod不要）。構造物チェストにオーバーリミット装備を足し、強化Mobとワールドイベントを追加します。見た目用のリソースパックがセットです。

## 必要環境

- Minecraft Java Edition **26.2**
- データパックのみで動作します（Fabric / Forge などの Mod は不要）
- 任意: [Dungeons and Taverns](https://modrinth.com/datapack/dungeons-and-taverns) と併用できます

## 入れ方

1. **データパック** `over_limit_pack.zip` を、ワールドの `datapacks/` に置く
2. **リソースパック** `over_limit_resources.zip` を、クライアントの `resourcepacks/` に置き、ゲーム内で有効化する
3. ワールドに入る（または `/reload`）

注意:

- **まだ生成されていないチェスト**にだけ新しいルートが効きます。すでに中身が確定したチェストは変わりません
- フォルダと zip を同時に置かないでください（二重に効きます）
- Dungeons and Taverns を使う場合は、本パックを **DnT より後**に読み込ませてください
- GitHub の Source ZIP は一段ネストするため、そのまま `datapacks/` や `resourcepacks/` には置けません。配布 zip を使ってください
- リソースパックを入れないと、クラフトアイテムの見た目が欠落テクスチャになります

## 戦利品

既存のチェスト中身は残し、**追加プール**でオーバーリミット装備を足します（0〜2個。だいたい 1 個）。

- 剣 / 斧 / 槍 / ツルハシ / シャベル / クワ
- 防具（ヘルメット・チェスト・レギンス・ブーツ）
- エンチャント本 / 釣り竿 / クロスボウ
- **帰還の懐中時計**（右クリックで1つ消費してリスポーン地点へ。64までスタック）
- 対象チェストごとに、バニラの不死のトーテムが別枠で稀に出ます（護符クラフト用）
- 素材はダイヤが多く、鉄とネザライトは少なめです
- 装備・本には **消滅の呪い**が必ず付きます（トーテムと帰還の懐中時計は例外）
- バニラ上限を超えるエンチャントが付くことがあります（チェスト付与のみ。エンチャント台・司書はバニラのまま）
- 金床で合成・修理・改名すると、上限超えのバニラエンチャントは通常上限に戻ります

## クラフト

チェストには出ません。クラフトでのみ入手します。

| アイテム | 作り方 | 効果 |
| :--- | :--- | :--- |
| **不死鳥の護符** | 不死のトーテム3つを横一列 → 2個 | トーテムと同じ致死回避。16までスタック。発動ごとに1減る |
| **黄金弓** | 弓を中心に金ブロック8個 | 耐久・矢速・ダメージが弓の約2倍。命中で発光。金ブロックで修理 |
| **静寂のトーテム** | ダイヤブロック1＋ダイヤモンド4 | 発生中のブラッドムーン／ネザーオーバーフロー／ネザーレイズ／シティクランプを、報酬なしで止める |
| **聖王のトーテム** | 上段金ブロック×3、中段静寂のトーテム×3、下段中央金ブロック | 使用すると1つ消費し、世界圧を0にリセットする |

## 強化Mob

敵Mobの一部が、出現時に次のいずれかに強化されます（名前付きMob、ドラゴン、ウィザー、ウォーデンは対象外）。

| 段階 | 目安 | 体力 | 攻撃 | その他 |
| :--- | :--- | ---: | ---: | :--- |
| WARNING | よく見る | ×2 | 通常 | 鉄ヘルメット |
| DANGER | ときどき | ×4 | ×2 | ダイヤヘルメット |
| CRISIS | 稀 | ×6 | ×3 | ネザライトヘルメット。少し大きい |
| DISASTER | ごく稀 | ×10 | ×5 | ネザライトヘルメット。さらに大きい |

強化Mobの経験値は通常より少なめです。世界圧が上がると、平時でも強化が出やすくなります。

## イベント

| イベント | 概要 |
| :--- | :--- |
| **ブラッドムーン** | オーバーワールドの夜。強化敵だけが出現する。100体撃破か朝で終了。撃破クリア時のみ報酬本 |
| **ネザーオーバーフロー** | ネザーポータル周辺の防衛。失敗するとゲート周辺がネザー化する。ブラッドムーンとは同時に起きない |
| **ネザーレイズ** | ネザーの要塞／バストリオンが蜂起する。未クリアの構造物を鎮圧する。オーバーフローの対 |
| **シティクランプ** | エンドシティで、本来いない敵も含むカオスを鎮圧する。本島では起きない |
| **ブラッドワールド** | 別ディメンション。夜は抽選なしでブラッドムーン相当。泣く黒曜石のポータルで往復 |

ネザーレイズとシティクランプは離れた構造物が戦場になります。発生するとチャットに座標が出て、ロケーターバー（経験値バーの上）に戦場のウェイポイントが立ちます。ボスバーのゲージは戦場までの残り距離で、32マス以内に着くと戦闘が始まります。着くまで敵は湧かず、制限時間も進みません。

イベントの難度は **脅威指数**（勝つほど次がキツい）で上がります。発生中のイベントは静寂のトーテムで止められますが、報酬は出ず、**世界圧**が少し上がります。世界圧が高いと、平時の強化Mobやブラッドムーンの発生が増えます。戦わずに夜を過ごし続けると、3日おきに世界圧が上がります。聖王のトーテムを使うと世界圧を0に戻せます。

イベント中は、戦闘で被弾すると約35%の確率で装備の耐久が追加で減ります（**消耗**）。削れ幅は脅威指数で決まります。
