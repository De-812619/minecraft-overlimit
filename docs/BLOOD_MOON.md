# ブラッドムーン

Minecraft Java **26.2** / pack format **107.1**・**データパックのみ**（Modなし）前提。  
本ドキュメントはイベント「ブラッドムーン」の仕様・決定事項・数値調整用。戦利品・強化Mobの正は [CONTENT.md](./CONTENT.md)。

**実装状態:** 実装済み（数値はプレイして調整）

---

## 現状サマリ

オーバーワールドの夜イベント。3日に1回、夕方に30%で発生し、強化敵（WARNING / DANGER / CRISIS）だけが出現する。100体撃破か朝で終了。撃破クリア時のみ、終了時にオーバーワールドにいる全員へカスタムエンチャント2つ＋消滅の呪いの本を渡す。


| 判定    | 内容                                                       |
| ----- | -------------------------------------------------------- |
| ○ 実装可 | 発生判定、ボスバー、睡眠禁止、強化100%、感知拡大、撃破／朝終了、報酬本、イベント産強化Mobの一括デスポーン |
| △ 近似  | カメラFOVそのものは変えられない。「ネザーっぽい視界」は霧の色＋距離で強制する                 |

## 決定事項

進捗: `[ ]` 未決 / `[x]` 決定済み。

### D1. 視界（霧・狭窄）

- [x] **決定:** ネザーに近い霧で画面を染め、霧の距離で視界を強制的に狭くする

26.2 の環境属性（`visual/fog_color` / `visual/fog_start_distance` / `visual/fog_end_distance`）を使う。開始 10 ブロック、不透明はネザーと同じ **96**（32 だと画面が黒く潰れた）。

- ワールドボーダーの赤い縁は使わない（ボーダー設定と衝突し、色もネザー霧ではない）
- **盲目・暗闇は使わない**（霧色が黒に上書きされ、ネザー感が消える）
- カメラFOV（画角）を変える属性は 26.2 に無い。ビデオ設定の FOV はプレイヤー側のまま。遠くが見えないことは霧で強制できる
- 実装手段の第一候補: カスタム World Clock ＋ Timeline。イベント開始で時計を「霧ON」キーフレームへ、終了で「無効果」へ戻す。オーバーワールドの Timeline タグへ `replace: false` で追加する
- カスタム World Clock は **初回だけクライアント／ワールドの再起動が必要**（`/reload` では登録されない）
- Clock の切替が検証で不安定なら、フォールバックを別途決める（この時点では第一候補のみ）

数値は [数値調整](#数値調整) の N1〜N4。

### D2. イベント産Mobのデスポーン

- [x] **決定:** 提案どおり


| 終了理由    | イベント中に強化した敵             |
| ------- | ----------------------- |
| 100体撃破  | 残っている個体もデスポーンさせる（報酬は出す） |
| 朝で自動終了  | 同上                      |


- 消す対象は **このイベントでスポーンし、強化した敵だけ**（専用タグ。仮: `overlimit.blood_moon`）
- 消さない: イベント前からいた WARNING / DANGER / CRISIS、プレイヤーが名札で名付けたMob、ネクロマンシーの魂、サモンの狼
- 「名前付きを全部消す」はしない（名札付きペット・村人を巻き込むため）
- 強化は `CustomName` が付くので自然デスポーンしない。終了時の一括削除が必須



### D3. 発生条件

- [x] **決定:** ゲーム時間で3日に1回、30%の確率。3日目の夕方に判定し、朝に自動終了

- Minecraft のオーバーワールド時計は 0 始まり。最初の判定は **day が 2 の夕方**（3日目）。26.2 では `time query time`（累計tick）を 24000 で割って日・日内時刻を出す
- 以降は day が 5, 8, 11…（`day % 3 == 2`）の夕方に振る
- 失敗（70%）したら次の該当日まで待つ。発生した夜の翌該当日も通常どおり振る
- 夕方は `daytime` の帯で1回だけ判定する（ちょうど 12000 を逃さない）
- 発生中は睡眠できないので、睡眠スキップで朝終了を回避されることはない

帯の幅は N5。朝の終了時刻は N6。

### D4. 睡眠

- [x] **決定:** 発生中はベッドで寝られない

第一候補は環境属性 `gameplay/bed_rule` の `can_sleep: never`（D1 と同じ Timeline）。失敗時は睡眠開始を検知して起こし、メッセージを出す。

### D5. 出現する敵

- [x] **決定:** 発生中に新規スキャンする `#overlimit:can_be_danger` は、通常個体を出さず WARNING / DANGER / CRISIS のいずれかにする

- 既存の `mob/scan` をイベント中だけ分岐する
- 既に `CustomName` がある個体は今どおり対象外
- ネクロマンシー／サモンは今どおりスキャン対象外を維持する
- ドラゴン・ウィザー・ウォーデンは今どおり対象外
- スポナー／試練は 100% 強化の対象外（D11）。通常の 16% ロールはかける
- 内訳の比率は N7（仮: WARNING 80% / DANGER 15% / CRISIS 5%）



### D6. 感知範囲

- [x] **決定:** 発生中に強化した敵へ `follow_range` を足す

倍率・加算量は N8。イベント前からいた強化Mobには付けない。終了時に個体を消すので、範囲の剥がし処理は不要。

### D7. ボスバー

- [x] **決定:** 発生中はボスバー名「ブラッドムーン  0/100体」をオーバーワールドのプレイヤーに表示する

- 色は赤
- テキストは **撃破数**（`0/100体`。ワールド共有）
- ゲージは **朝までの残り時間**（夕方 12000 → 朝 23460 で満タン→空。強制開始が夜ならその分だけ減った状態から始まる）
- ワールド共有の1本（個人バーにしない）



### D8. 終了条件

- [x] **決定:** 次のどちらか先に満たした時点で終了する

1. イベント産の強化敵を **合計100体** 倒す（ワールド共有。N9 / N10）
2. 朝になる

カウント対象はイベント産の強化敵だけ（動物・イベント前のエリート・ネザーのピグリン等は含めない）。

### D9. 報酬

- [x] **決定:** 100体撃破で終了したときだけ、カスタムエンチャントが **2つ** 付いたエンチャント本を1つ渡す。朝終了では渡さない

- 配布先は終了時に **オーバーワールドにいるオンライン全員**（N11）
- **消滅の呪いを付ける**（N12。チェストのボーナス本と同じ）
- 対象エンチャントはボーナス本と同じカスタム枠（フェニックス・ドッペル・アストラルは除外。風の加護は含む）
- 2つは **異なる** エンチャント。排他（精錬×ハイパーディグ、暴食×ソウルテイカー）が同時に当たったら振り直す
- バニラ強化（ダメージ増加など）は付けない

### D10. 対象ディメンション

- [x] **決定:** オーバーワールドのみ

霧・強化100%・ボスバー・睡眠禁止・撃破カウント・報酬配布はオーバーワールド。ネザー／エンドにいるプレイヤーにはイベントをかけない（ネザーにネザー霧を重ねない、エンドのシュルカーを全強化しない）。

### D11. 100%強化の除外（負荷）

- [x] **決定:** スポナー由来と試練の間は 100% 強化しない。襲撃とファントムは含める

名前付き強化は自然デスポーンせず、Marker と広い感知が毎tick残る。狭い場所への連続スポーンがチャンク負荷の主因なので、そこだけ外す。

| 対象 | 100%強化 | 通常の16%ロール | 理由・手段 |
| --- | --- | --- | --- |
| モンスタースポナー付近 | しない | する | ダンジョン・廃坑・要塞・プレイヤー農場。由来フラグが無いので、スキャン時に近くの `spawner` を見てスキップ（半径は N19） |
| 試練の間 | しない | する | 試練スポナーの波。構造物 `trial_chambers` 判定（必要なら近くの `trial_spawner` も） |
| 襲撃（レイダー） | する | — | 波に上限があり、ワールド全体の負荷にはなりにくい |
| ファントム | する | — | 数は少ない。飛行 AI は個体あたり重いが、除外するほどではない |

仕様の未決は以上で閉じる。残りは [数値調整](#数値調整) の仮値。

## 仕様



### 発生

1. 毎日、夕方帯に入った最初の tick で「今日は判定日か」を見る（`day % 3 == 2`）
2. 判定日なら 30% を1回だけ振る。成功で開始、失敗でその日は何もしない
3. 開始時: ボスバー表示、霧ON、睡眠禁止、強化ロール切替、撃破カウンタ 0

強制開始コマンドは実装時にテスト用へ足す（[TESTING.md](./TESTING.md) に追記予定）。

### 発生中

- 新規の対象敵は WARNING / DANGER / CRISIS にし、`overlimit.blood_moon`（仮）を付ける（スポナー付近・試練の間は除く。そこは通常の16%ロール）
- 感知範囲を広げる
- ボスバーは時間で減り、テキストは撃破数（`0/100体`）
- ベッド不可

発生前からいた通常敵・強化敵はそのまま。朝まで残っても、終了時の一括削除の対象にはならない。

### 終了

共通: 霧OFF、睡眠禁止解除、強化ロールを通常に戻す、ボスバー削除、イベント産強化敵をデスポーン、フラグとカウンタをリセット。


| 理由    | 追加                   |
| ----- | -------------------- |
| 100体撃破 | 報酬の本を配布              |
| 朝     | 本は出さない。タイトル等の終了演出は任意 |


`/time set day` で朝扱いになった場合も朝終了と同じ。

### 報酬本（100体時）

1冊のエンチャント本にカスタム Lv1 を2つ＋消滅の呪い。抽選は等確率。終了時にオーバーワールドにいるオンライン全員へ1冊ずつ。詳細は N11〜N13。

## 技術メモ（実装時）

- 名前空間: `overlimit`
- tick: `overlimit:tick` から `execute in minecraft:overworld run function overlimit:blood_moon/tick`
- 強化分岐: `overlimit:mob/scan` → イベント中かつオーバーワールドなら `scan_blood_moon`（スポナー付近・試練の間は `scan_normal`）
- 撃破: `overlimit:blood_moon/on_kill`（`player_killed_entity` + `minecraft:entity_tags`）
- 霧・睡眠: `data/overlimit/world_clock/blood_moon.json` ＋ `data/overlimit/timeline/blood_moon.json` ＋ `data/minecraft/tags/timeline/in_overworld.json`（`replace: false`）
- 報酬ルート: `overlimit:blood_moon_book`（カスタム2つ＋消滅の呪い。排他ペアなし）
- 強制開始: `/function overlimit:blood_moon/force_start`（夜にして開始）
- カスタム World Clock は初回だけ **タイトルへ戻って入り直し**（`/reload` では登録されない）



### 既存処理との交差


| 既存                        | 扱い                                                     |
| ------------------------- | ------------------------------------------------------ |
| WARNING / DANGER / CRISIS | イベント中はロールだけ変える。ステータス定義は [CONTENT.md](./CONTENT.md) のまま |
| ネクロマンシー／サモン               | 対象外のまま                                                 |
| カスタムエンチャントのクールダウン         | 変更しない                                                  |
| チェストのボーナス本                | 変更しない。イベント報酬は別ルート                                      |




### 既知の制約

- 霧はカメラ位置のバイオームと補間される。洞窟と地上で濃さが少し違うことがある
- 水中は `visual/water_fog_*` が別。地上用だけ変えると水中はバニラのまま（必要なら N を足す）
- `doDaylightCycle false` / `advance_time false` だと発生も朝終了もしない
- Peaceful だと撃破クリアはほぼ不可能で、朝終了のみ
- モブキャップは同じでも耐久が高いので、100体が夜に届かないことがある → N7 / N9
- スポナー除外は近似（近くにスポナーがあるか）。スポーン後に歩いて離れた個体は 100% 強化されうる。試練は構造物判定の方が正確

## テスト観点（実装後に TESTING.md へ移す）

- 強制開始 → 霧色と距離、ボスバー、ベッド不可
- 地上の自然スポーン敵は名前付き強化で、感知が広い
- ダンジョンスポナー付近・試練の間の敵は 100% 強化されない（通常の 16% はあり）
- 襲撃・ファントムは 100% 強化される
- 100体で本が1冊（カスタム2つ＋消滅の呪い）、残敵が消える。オーバーワールドにいる全員が貰う
- ネザーにいるプレイヤーは本を貰わず、霧・強化100%もかからない
- 朝終了で本が出ず、残敵が消える
- イベント前の WARNING が朝に残る
- 名札付きゾンビが消えない
- 判定日以外の夕方に起きない
