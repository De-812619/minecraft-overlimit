## 技術前提（共通）

### 使える仕組み

- カスタムエンチャント定義: `data/overlimit/enchantment/*.json`
- 効果トリガー例: `post_attack` / `hit_block` / `tick` / `armor_effectiveness` / `attributes` など
- 複雑挙動: 効果から `run_function` → `overlimit:enchant/...` の mcfunction
- 付与経路（現状方針と整合）: チェストの `set_enchantments`（台・司書に出すかは別決定）
- 表示名: エンチャント JSON の `description`（必要なら後から lang／リソースパック）

### データパックの限界（全体に効く）


| 限界                                        | 影響する候補               |
| ----------------------------------------- | -------------------- |
| プレイヤーの Motion はクライアント主導で不安定               | スカイウォーク                     |
| `death_protection` は**手持ちのみ**有効（防具スロット不可） | フェニックス（**保留**・下記 A2） |
| プレイヤー完全複製（スキン＋能力＋AI）は不可                   | ドッペル（**保留**）         |
| 真の非実体化（ブロック貫通）は不可                         | アストラル（ダメージ無効で回避済み）   |
| tick 広範囲セレクタは負荷大                          | 千里眼、超重力、ハイパーディグ      |


### 既存方針との関係

現行ボーナスは「バニラ上限超え」＋**消滅の呪い必須**＋台／司書はバニラのまま。  
カスタムは **D1=案A・D4=案A** により、同じ追加エンチャント枠へ行追加する（台には出さない）。

### W8 インパクト — ○（テスト可）

**要件:** 斧で殴ったMobを中心に、クリーパー相当の爆発（ダメージあり）。殴りダメージとは別。地形は壊さない。プレイヤーはダメージもノックも受けない。

**実装方針:** `post_attack`（直接攻撃・victim＝プレイヤー以外）→ CD確認 → ヒット位置で演出（`explosion_emitter`＋`entity.generic.explode`）＋半径6内のMobへ距離減衰ダメージ（`player_explosion`）＋ノック。ブロック破壊はしない（本物の `/summon creeper` は使わない）。

**制約**

- 爆発ダメージは Normal・遮蔽なしの近似（難易度・壁越し減衰はバニラクリーパーと完全一致しない）
- スプラッシュキルはプレイヤー起因（`by` 攻撃者）なので、同じ斧の暴食などが乗る可能性がある
- アーマースタンド／マネキンは対象外（Mobではない）

**決定済み**

- [x] 付与先：斧
- [x] 発動：Mobを殴ったとき（ブロック殴りではない）
- [x] CD：10秒
- [x] 地形破壊：しない
- [x] プレイヤー：ダメージなし・ノックなし
- [x] 対象：プレイヤー以外のすべてのMob（村人・動物・味方召喚も含む）
- [x] 中心付近ダメージ：22（≈クリーパー power 3・至近・Normal）
- [x] 有効半径：6（power 3 のエンティティ半径）
- [x] CD中表示：足元＋右手（斧）付近に `smoke`（本人のみ・アクションバーなし）
- [x] CD完了音：`item.crossbow.loading_end`（本人のみ）

**メモ:** 右クリック起動は斧の使用検知と盾・皮剥ぎ競合のため不採用。CDフィードバックはパーティクルのみ。

### A2 フェニックスの加護 — △（**保留・方式未定**）

**状態:** 実装・方式決定とも **一旦保留**。ボーナス枠への組み込み・Phase 実装からも除外する。再開時はこの節の比較表から議論を再開する。クラフトアイテム「不死鳥の護符」（トーテムのスタック版）とは別物。

**要件（原案・変更なし）:** 致死時に死亡回避＋爆発＋体力50%回復。CD 3分。トーテム上位互換。

**保留理由:** 「防具エンチャだけで致死回避」と「トーテム同等のきれいさ（死亡しない・オフハンド不要）」がデータパックでは両立しにくい。

#### 技術制約（確定）

- `minecraft:death_protection` はトーテムと同じパイプライン（致死時に消費・HP=1）。
- **メイン／オフハンドのみ有効。防具スロット直付けでは発動しない。**
