# 拠点防衛（ネザーオーバーフロー）

Minecraft Java **26.2** / pack format **107.1**・**データパックのみ**（Modなし）前提。  
本ドキュメントはイベント「拠点防衛（ネザーオーバーフロー）」の**企画レビュー**。実装前の実現可否・懸念・未決を置く。戦利品・強化Mobの正は [CONTENT.md](./CONTENT.md)。発生の排他は [BLOOD_MOON.md](./BLOOD_MOON.md)。

**実装状態:** 実装済み（数値はプレイして調整）

## 現状サマリ

オーバーワールドのネザーポータルを起点に、ピグリンブルート・ピグリン・ガストが **コア所持プレイヤー** へ進行する防衛イベント。所持者の死亡、または制限時間切れでゲート周辺がネザー化する。夕方6回に1回、制限30分（10分×3フェーズ）。勝利は敵の殲滅のみ。ブラッドムーンとは同時に起きない。

データパック単体で **戦闘イベントとしては実装できる**。ネザー化は地表ブロック置換の近似。発生間隔はゲームの夕方回数。D1〜D12 は決定済み。報酬の内訳も決定済み。残りは数値のプレイ調整。


| 判定 | 内容 |
| --- | --- |
| ○ 実装可 | 30分タイマーと3フェーズ、強化召喚、ピグリンのゾンビ化防止、コアのタグ付与、BM排他、ボスバー、終了時デスポーン |
| △ 近似 | ネザー化（地表の自然地面のみ置換）、敵の行軍（Brain `angry_at`。隊列は不可）、発生間隔（夕方6回。OS日付は読めない） |
| × 不可／非推奨 | OSカレンダーの正確な3日、ワールド全ポータルの一括スキャン、既存チャンクのネザー地形再生成、失敗範囲の完全な巻き戻し |

## 企画の読み取り

提案文を、実装に落とすときの作業仮説として置く。**未決のまま実装しない。**

1. オーバーワールドの**バニラネザーポータル**付近から敵が出て、拠点側へ進む
2. ピグリン／ブルートは強化Mob。ガストは強化しない。ピグリンはゾンビ化しない
3. 防衛に失敗するとゲート中心がネザー化する（初回半径8、以降 +4）
4. 間隔はリアル時間で約3日に1回。1回あたり30分
5. オーバーワールドのブラッドムーンとはどちらか一方だけ
6. コア所持者の死亡、または制限時間切れで防衛失敗（ネザー化確定）
7. フェーズは10分ごと。進むほど強化段階が上がる


| フェーズ | 時間 | 強化 | スポーン数 |
| ----- | -- | -- | ------ |
| 1 WARNING | 0〜10分 | 全ピグリン／ブルートを WARNING | 100体/10分 |
| 2 DANGER | 10〜20分 | 全ピグリン／ブルートを DANGER | 70体/10分 |
| 3 CRISIS | 20〜30分 | 全ピグリン／ブルートを CRISIS | 30体/10分 |

ガストの内訳・各フェーズの出現数は提案に無い。

## 決定事項

進捗: `[ ]` 未決 / `[x]` 決定済み。D1〜D12 と報酬内訳は閉じた。残りは数値のプレイ調整。

### D1. 対象ゲート

- [x] **決定:** プレイヤーが近づいたバニラネザーポータルを登録し、発生時はオーバーワールドにいるオンラインプレイヤーから最も近い登録門 **1つ** だけを攻める

- 登録: 開始時に OW プレイヤーから水平半径 **32**・高さ ±16 の `nether_portal` をスキャンして Marker に残す（N21）。隣接タッチの毎tick登録も残す。ワールド全スキャンはしない
- 発生時: 登録済みかつ枠が残っている門のうち、OW にいるプレイヤー（スペクテイター除外）からの距離が最小の1つ
- 同時に複数門は開かない
- ブラッドワールドの泣く黒曜石門は `nether_portal` 実ブロックではないので対象外（[BLOOD_WORLD.md](./BLOOD_WORLD.md)）
- 一度も近づいていない門は対象外
- 登録門が0、または開始時点で OW に対象プレイヤーがいないときは開始しない
- 枠が壊れた Marker は登録から外す

### D2. コア

- [x] **決定:** コアは物理アイテム／設置物ではない。開始時、対象ゲートから最も近いオーバーワールドのプレイヤーへ **タグで強制付与**する。ピグリン／ブルートはその所持者へ行軍する

- 所持者の識別: タグ（仮 `overlimit.no_core`）。見た目は発光・粒子・ボスバー上の名前など。インベントリは占有しない
- 開始時の選出: スペクテイター以外、OW にいるプレイヤーのうち門からの距離が最小。同距離なら選出順は任意
- 所持者が OW からいなくなった（ログアウト・ネザー／エンド／ブラッドワールド）ときは、OW に残っている次に近いプレイヤーへ移す。移す相手が誰もいなければタイマーを止める（D11）
- 死亡での移譲はしない（死亡は敗北）
- ゲート前のコアブロックは置かない（以前の設置案は破棄）

### D3. 成功／失敗

- [x] **決定:** 失敗はコア所持者の **死亡（死因を問わない）**、または **制限時間（30分）切れ**。成功は **Ph3 の予算を使い切りピグリン／ブルートが 0** だけ（フェーズ繰り上げの結果、30分より前になりうる）。時間経過だけでは勝たない。イベント敵からの被弾では敗北しない

- トーテムで耐いだ場合は死亡していないので続行
- 転落・溶岩・他プレイヤーで死んでも死亡敗北
- 早期殲滅: Ph3 の予算を使い切り、かつピグリン／ブルートが残っていない。Ph1/Ph2 で場が空なら勝利せず次フェーズへ繰り上げ（D8）
- 制限時間切れは敗北（ネザー化）。箱に籠る・門から離れて待つだけでは勝てない
- 成功報酬: 対象ゲート付近にチェスト **1つ**（マルチは分け合う。BMのような人数分は置かない）
- 中身（確定）:
  - 装備 **5**（`overlimit:bonus_gear` と同じ抽選だが、**本と懐中時計は出さない**。武器・道具・防具のみ。消滅の呪い＋上限超えバニラ／カスタムはチェストボーナスと同じ）
  - カスタム本 **3**（ブラッドムーンと同じ。カスタム Lv1 を異なる2つ＋消滅の呪い）
  - 帰還の懐中時計 **3**（消滅の呪いは付けない）
- 早期殲滅と制限時間内の殲滅は同じ中身
- 失敗時は報酬なし（死亡・時間切れいずれも）
- チェスト名は仮「ネザーオーバーフローの報酬」。置き方は門の正面（歩行方向）2〜3マス。ネザーラックや巨大キノコごと置き換える。門・黒曜石・既存コンテナは壊さない。置けなければその場ドロップ

### D4. ネザー化の中身

- [x] **決定:** 失敗時は **ブロック置換のみ**（`fillbiome` はしない）。初回はゲート中心の水平半径 **8**、以降は失敗のたびに **+4**（8→12→16→20…）。チャンク境界にはスナップしない

- 置換対象: 地表付近の草・土・石など自然の地面系。門相対の 8×8 区画ごとにバイオームを決め、区画内は主ブロック＋少しのアクセント（`fillbiome` はしない）
  - ネザー荒地: ネザーラック中心、少しブラックストーン／ソウルソイル
  - 真紅の森: 真紅のナイリウム中心。空きがあれば真紅の巨大キノコ
  - 歪んだ森: 歪んだナイリウム中心。空きがあれば歪んだ巨大キノコ
  - ブラックストーン: ブラックストーン中心、少しネザーラック／玄武岩
  - 玄武岩デルタ: 玄武岩中心、少しブラックストーン／ネザーラック
- 空き: 真紅／歪んだ区画で、ナイリウムの上にキノコを置いてバニラの `crimson_fungus_planted` / `warped_fungus_planted`（骨粉と同じ巨大キノコ）を約5%。失敗したら小さなキノコのまま。加えて約18%で根・キノコ・ネザースプラウト。屋根の直上は出さない
- 残す: 水、木、建築ブロック、チェスト、ベッド、ポータル枠（黒曜石）
- 水→溶岩、高さ全体の置換はしない
- 厚さは地表高さマップ ± 数ブロック（N13）。地下拠点は巻き込まない
- 一度塗った範囲はセーブに残る。成功しても戻さない。置換前の完全な巻き戻しは持たない
- **侵食回数は門ごと**（Marker のスコア）。ゲートAで3回敗北しても、新しく作ったゲートBは初回半径から。枠が壊れて Marker が消えた門は回数も消える
- 半径は N11 + N12×その門の敗北回数（初回8、次12、次16、次20…）

既存チャンクをネザー地形として再生成することはできない。`fillbiome` もしないので、空・霧・草の色・ネザー音楽はバニラのまま。昼間の天空光も残る。地面は区画ごとにネザーバイオーム風のブロックがまとまる。

### D5. 発生間隔（「リアル時間3日」）

- [x] **決定:** 毎tickの経過時間は使わない。ブラッドムーンと同じ夕方帯（`12000..13000`、その日1回）でスコアを+1し、**X 回の夕方ごと**に発生判定する

- OS の日付は読めない。「リアル3日」はゲームの夕方回数で近似する
- 負荷: 既存の `blood_moon/tick` が夕方帯を見ている。本イベントは同じタイミングでカウンタを1足すだけ（毎tick加算や全ポータルスキャンはしない）
- 発生したらカウンタを0に戻す。ワールド開始直後の最初の夕方では起きない（X 回溜まってから）
- **X = 6**（ゲーム6夕ごと。昼夜サイクルが動いていれば約2時間に1回。N1）
- 排他でスキップした夕方は D6 で「数える／数えない」を決める

発生中にワールドを閉じた場合のタイマーは D11（防衛30分の進行。夕方カウンタはワールドの昼夜に従う）。

### D6. ブラッドムーンとの排他

- [x] **決定:** オーバーワールドの抽選ブラッドムーンとは同時に起きない。**同じ夕方に両方来たら防衛を開始し、BM はその夜スキップ。** 防衛の30分中に来る夕方でも BM は開始しない

- スキップした BM は外れに数えない（確率 +20% しない。次回も同じチャンス）
- ブラッドワールドの夜イベントは独立（現状どおり。OW 防衛中でも BW 側は夜になれば始まる）
- 実装: `#no_active` 中は `blood_moon/try_start` を打たない。防衛の発生判定は `#bm_active` が 1 なら延期せず、その夕方は防衛を取り BM を欠番にする（両方アイドルで同時のとき防衛優先）
- BM 発生中に夕方カウンタが X に達した場合: その回は防衛を開始しない。カウンタは D5 どおり（スキップした防衛判定を「消費したことにするか」は、X=6 を待つ側に残す＝カウンタを戻さず次の夕方に再判定、が自然。**防衛の開始を1夕遅らせる**）

補足: 「同じ夕方に両方」は防衛優先で BM 欠番。「BM がすでに夜の途中」は防衛を1夕ずらす。30分防衛は必ず夕方を跨ぐので、跨いだ側の BM は欠番。

### D7. スポーンと「進行」

- [x] **決定:** 敵は対象ゲート中心の水平半径 16（1チャンク）の地表付近に出す。ピグリン／ブルートはコア所持者へ強制敵対して行軍する。ガストはコア所持者を索敵する

- 門の中（`nether_portal` 内）には出さない。所持者の足元・隣には出うる
- 高さは門の Y 付近（高さマップ地表だけだと、高架の門／地下の門でずれる）。門 Y ±4 を目安（N10）
- 金防具でも中立にしない（イベント個体は Brain の `minecraft:angry_at` を所持者 UUID へ。スポーン時に所持者からの 1 ダメージで Heavy aggravation。`AngryAt` はピグリンが使わない）
- 厳密なウェイポイント隊列は使わない。パスが詰まると門周辺に溜まる
- コア所持者が門から離れると、門→所持者への行軍になる（キテ可能。同時上限と N18 で抑える）

### D8. フェーズとスポーン数

- [x] **決定:** 100 / 70 / 30 は各フェーズの **出現予算**。同時生存は **12**。前フェーズの生き残りは持ち越す（キャップ中は新規を出さない）。場が空かつそのフェーズの予算を使い切ったら、10分待たずに **次フェーズへ繰り上げ**

- 「スポーン率が上がる」は質（WARNING→DANGER→CRISIS）の上昇。体数は減らす
- フェーズの最大長は 10 分。予算が残っていても 10 分で次へ（生き残りは残す）
- 繰り上げ条件: そのフェーズで出した数が予算に達し、**かつ** ピグリン／ブルートが 0。ガストは別枠なので数えない。キャップで止まっている途中では繰り上げない（100 体倒し切る必要がある）
- Ph3 を同様に消化してピグリン／ブルートが 0 なら勝利（30分より前になりうる）。残ったガストは終了時に消す
- 開始から 30 分経っても場が残っていれば敗北（ネザー化。D3）。時間切れで勝たない
- ガストを予算の内数にするかは D9
- CRISIS はサイズ 1.5 倍。半径 16 に 12 体は密集する。屋根が低いと窒息しうる

### D9. ガスト

- [x] **決定:** 各フェーズの出現上限 **5**。同時最大 **1**。倒されたら **1〜60秒**のランダム間隔を空けて補充。ピグリン／ブルートの予算とは **別枠**（勝利・繰り上げ判定にも入れない）。強化しない。火球の地形破壊はバニラ（`mobGriefing`）に任せる

- コア所持者を索敵する。門の中には出さない。高さは地表から数マス上（狭所はスキップ）
- 同時上限 12 に含める（ピグリン 12＋ガスト追加にはしない）。場が12で埋まっている間は補充を待つ
- フェーズ開始時は1体目をすぐ出す。フェーズをまたいで生き残った1体は、次フェーズの5回に含める
- そのフェーズのピグリン／ブルート予算を使い切り場が空なら、ガストの補充を止める（無限に勝てなくならないように）
- 天井が低くて出せない地点はスキップ（無理に狭所へ出さない）
- イベント中だけ `mobGriefing` を切ることはしない（他の爆発・エンダーマンも変わるため）

### D10. 対象ディメンションと参加者

- [x] **決定:** イベントはオーバーワールドの対象門だけ。ネザー側の対向門には出さない。Peaceful では開始しない

- 所持者がネザー／エンド／ブラッドワールドへ入ったらコアを OW の別人へ移す（D2）。戦闘とスポーンは OW のまま
- 開始時に対象門周辺を `forceload` する（終了で外す）。プレイヤーが離れても門チャンクは落とさない
- ボスバーはオーバーワールドのプレイヤーに出す（BM と同じ）。ネザーにいる人には出さない
- Peaceful 判定はブラッドムーンと同様 `difficulty` の store。開始後に Peaceful へ変えた場合は未決→ **その時点で無効終了（ネザー化なし）** を仮にする

### D11. 中断

- [x] **決定:** OW にコアを渡せる人が誰もいない間はタイマーとスポーンを止める。戻ったら続きから。発生中にポータル枠が壊れても、門の座標のまま最後まで続ける

- 停止中はフェーズ繰り上げ・成功・失敗を判定しない（予算消化済み＋場が空を勝利／繰り上げにしない）
- 停止中の敵は forceload した門周辺に残す。再開時にコアは、その時点で門に最も近い OW プレイヤーへ付け直す
- 再開後も残り時間・残り予算はそのまま
- 枠が無くてもネザー化の中心は登録座標。スポーンもそこを中心にする
- ワールドを閉じた場合はサーバが止まればタイマーも止まる（シングル）。専用サーバで空回りし続ける場合は「OW に誰もいない」と同じ停止

### D12. バニラ自然スポーン

- [x] **決定:** `spawn_monsters` は切らない。対象門付近の **名無しゾンビピグリン** だけ間引く

- イベント敵は `/summon`。バニラの地上湧き（ゾンビ等）は残る
- ポータルからのバニラゾンビピグリンが防衛と混ざるのを避けるため、門半径 16 程度の名無し `zombified_piglin` をデスポーン（撃破扱いにしない）
- 名札付き・イベントタグ付きは消さない
- ブラッドムーン発生中はこの gamerule を切っているが、D6 の排他で同時には起きない

## 仕様（作業仮説）

D1〜D12 が閉じたあとの骨子。報酬の内訳も含めこれを正にする。

### 発生

1. オーバーワールドで、間隔（D5）を満たし、BM未発生、登録門が1つ以上ある
2. 対象門を1つ選ぶ（D1）
3. 門から最も近い OW プレイヤーへコアタグを付与（D2）、ボスバー、フェーズ1、スポーン予算リセット
4. 対象チャンクを forceload（終了で外す）

強制開始はテスト用に足す（[TESTING.md](./TESTING.md) へ後で追記）。

### 発生中

- 10分ごとに Ph2 / Ph3。そのフェーズの予算を使い切り場が空なら、10分待たずに繰り上げ
- 同時生存 12。キャップ中は出さない。前フェーズの生き残りは残す
- ピグリン／ブルートは `IsImmuneToZombification:1b` を付けてから、そのフェーズの `make_warning` / `make_danger` / `make_crisis` を直呼び（ロールしない）
- ガストは各フェーズ最大5・同時1（倒したら1〜60秒後に補充。別枠、同時12に含む）。強化スキャン対象外
- ボスバーは残り時間（ゲージとテキストの分秒）＋フェーズ名。OW のプレイヤーに表示
- 所持者死亡、または制限時間切れで失敗。Ph3 予算尽き＋ピグリン／ブルート0でのみ成功（ガストは残っていてよい）
- `spawn_monsters` は切らない。門付近の名無しゾンビピグリンは間引く

### 終了

共通: イベント敵デスポーン（専用タグ。名札ペット・ネクロマンシー・サモンは残す）、コアタグ解除、forceload解除、ボスバー削除、BM排他フラグ解除。


| 理由 | 追加 |
| --- | --- |
| Ph3 予算尽き＋ピグリン／ブルート0 | ネザー化しない。残ガストは消す。対象ゲート付近へ報酬チェスト1つ（装備5・本3・時計3） |
| コア所持者の死亡、または制限時間切れ | ネザー化（D4）。**その門**の失敗回数を+1して次回半径を広げる。報酬なし |

## 技術メモ（実装時）

- 名前空間: `overlimit`。関数は `overlimit:nether_overflow/` を想定
- tick: `overlimit:tick` から OW で呼ぶ。`#no_active` 中は BM の `try_start` を `return fail`
- コア所持: 開始時に門から最寄の `@a` へタグ。ボスバーにフェーズと残り時間。所持者変更は OW 離脱時のみ
- 行軍: ピグリン／ブルートの Brain `minecraft:angry_at` を所持者 UUID へ。スポーン時に所持者から `damage 1 player_attack`。`follow_range` は N16。金剣／金斧を持たせる（`/summon` のピグリンは素手）
- 出現: 門中心 `distance=..16` の立てる空気。`nether_portal` 内はスキップ。高さは門 Y ±4。開始時に 8 体バースト、以降は N22。ピグリン／ブルートはランク色で発光（WARNING金／DANGER赤／CRISIS紫）。ガストは発光しない
- 門の登録: 開始時にプレイヤーから水平 32・Y±16 をスキャン（N21）。隣接タッチでも Marker（`overlimit.no_gate`）。枠が消えたら Marker 削除
- ピグリン／ブルート: summon NBT で `IsImmuneToZombification:1b`。ディメンション属性 `gameplay/piglins_zombify` はオーバーワールド全体を変えるので使わない（ブラッドワールドだけ false）
- 強化: フェーズに応じて `mob/make_*` を直呼び。`scan` の16%ロールや BM の80/15/5には乗せない
- ガスト: `can_be_danger` に入っているので、イベントタグ付きは `scan` でスキップする
- ネザー化: 終了処理を先に済ませてから、数tickに分けて `fill replace`。8×8 区画のハッシュでバイオームを決め、真紅／歪んだ区画だけバニラの巨大キノコ（骨粉相当）
- 報酬ルート: `overlimit:nether_overflow_reward`（装備は本・時計除外の bonus_gear 相当を5回、本は `blood_moon_book` を3回、時計は `recall_watch` を3回）。門の正面（ポータルの歩行方向）へチェスト1つ。高さマップは使わず門と同じ高さ付近で、ネザーラック／ナイリウム／キノコごと置き換える。門・黒曜石・既存コンテナは壊さない
- 強制開始: `/function overlimit:nether_overflow/force_start`
- 時間切れテスト: `/function overlimit:nether_overflow/force_timeout`
- カスタム World Clock は本イベント必須ではない（霧を足すなら BM と同様、初回はタイトルへ戻る）

検証で NBT 名が 26.2 と違ったら `reference.md` に追記する。Wiki 上のピグリン個体データは `IsImmuneToZombification`（[Piglin](https://minecraft.wiki/w/Piglin)）。

## 既知の制約・懸念

### 戦闘

- 名前付き強化は自然デスポーンしない。キャップ無しの 100+70+30 は BM で避けた負荷そのもの
- ピグリンは金防具で殴ってこない。強制敵対を忘れるとブルートとガストだけになる
- 半径16は門前拠点だと所持者の足元に湧く
- ガスト火球は拠点を壊す（コアはプレイヤーなので火球では敗北しない。建築は壊れる）
- CRISIS の1.5倍サイズは門前の狭い空間と相性が悪い
- パスが詰まる（堀・水・1マス幅）と門に溜まり、所持者が近づくまでコアに届かない
- 所持者が門から離れてキテすると、敵はワールドを横断する。N8/N18 必須
- 30分のあいだ昼夜が約1.5周する。BMのような「夜だけ」ではない
- 門に立つとネザーへ送られる。送られた所持者はコアを失い、OW の別人へ移る（誰もいなければタイマー停止）
- コア所持者の「1死でワールドが傷つく」は BM より重い。トーテムは死亡を一度防ぐ

### ネザー化

- バイオームは変えないので空・霧はオーバーワールドのまま。地面は 8×8 区画でネザーラック／ナイリウム／ブラックストーン／玄武岩がまとまる
- ブロック置換は自然地面のみ。建築・水・木は残る
- 失敗のたびに半径が伸び、永久に残る。ワールドの可逆なペナルティではない
- 未ロードチャンクは塗れない。forceload 範囲と半径がずれると穴が空く

### 検出・スケジュール

- ワールド内の全ネザーポータルを毎tick探す手段は無い（連鎖長・チャンクロード）
- 壁時計3日はデータパックでは再現できない
- 対象門のチャンクが落ちると、コア破壊もスポーンも判定できない

### 数値の内部矛盾

- 「スポーン率が上がる」と 100→70→30 の減少は同時に真にならない。質の上昇で読むか、数値を逆転するか決める
- ガスト比率が空なので、仮の N19 を置いてもプレイで崩れる前提

## テスト観点（実装後に TESTING.md へ移す）

- 強制開始 → 対象門の半径16にピグリン系。15秒経ってもゾンビ化しない。最寄プレイヤーがコア（発光等）
- ガストに WARNING 名が付かない
- Ph1→2→3 で新規が DANGER / CRISIS になる
- BM強制開始中は本イベントが始まらない。本イベント中の夕方に BM が始まらない
- 成功時は門の隣にチェスト1つ（装備5・本3・時計3）。失敗時は死亡／時間切れでネザー化
- 予算尽き＋敵0で勝利 → Ph3 を消化して場が空。Ph1/2 で空なら次フェーズ繰り上げ。30分切れは敗北
- 所持者がネザーに入るとコアが OW の別人へ移る。OW が空なら停止して再開
- 枠を壊してもイベントは門座標で続く
- Peaceful では始まらない
- 2回目失敗で**同じ門**の半径が広がる。別門は初回半径
- 終了でイベント敵が消え、名札付きとネクロは残る
- ブラッドゲートだけでは始まらない
